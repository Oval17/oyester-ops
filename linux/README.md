# Linux

> Part of [Oyester-Ops](../readme.md)

## Goals

- [ ] Filesystem, permissions (`chmod`, `chown`), processes (`ps`, `top`, `kill`)
- [ ] `systemd` services, logs with `journalctl`
- [ ] Users, `sudo`, SSH hardening basics
- [ ] Disk / memory: `df`, `du`, `free`

## Cheat sheet

```bash
ls -la
chmod 644 file
ps aux | grep node
journalctl -u myservice -f
df -h && free -h
```
